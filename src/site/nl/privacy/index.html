Privacy

Murder Sudoku 3D is een gratis puzzelspel zonder accounts, advertenties of tracking. Deze pagina legt uit wat er met je gegevens gebeurt.

Laatst bijgewerkt: 11 oktober 2026

Op de website

Het spel heeft geen statistieken, geen cookies en geen advertenties. Het laadt niets van andere websites: de code, de 3D-bibliotheek en de lettertypes komen allemaal van de site zelf.

De website wordt gehost op GitHub Pages. GitHub kan technische gegevens vastleggen, zoals je IP-adres, om de dienst veilig te houden. Zie de privacyverklaring van GitHub.

Je voortgang

Er zijn geen accounts. Je voortgang, instellingen en taalkeuze worden alleen op je eigen apparaat bewaard, in de lokale opslag van je browser. Er gaat niets naar een server. Als je je browsergegevens wist, zijn ze weg.

Feedback

De feedbackknop opent een vooraf ingevuld formulier op GitHub in je browser. Als je het verstuurt, is je bericht openbaar en geldt de privacyverklaring van GitHub.

Contact

Vragen over privacy? Maak een issue aan op GitHub.
